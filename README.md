

#  Color Selector

This is a simple Color Selector web application that allows users to choose different color and instantly see the background change. it is a beginner-friendly project to practice basic web devlopment. 


## Features
- Select different colors
- BAckground color changes instantly
- Simple and clean user interface

## Technologies Used
- HTML
- Tailwind CSS
- JavaScript

## How to Use

1.Download or clone the repository
2.Open the project folder
3.Open index.html in your browser.
